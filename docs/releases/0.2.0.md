- Bundled Tanzil Uthmani 1.1 dataset: 114 surahs and 6,236 ayahs.
- Local database import at startup, with a payload checksum check.
- Quran source attribution and license notice in the reader.
- Generated Android, iOS, and Windows app icons from the checked-in SVG master.
